FraudX-2 leverages cutting-edge Machine Learning models and real-time monitoring to protect your business from fraudulent transactions. With an intuitive dashboard, additive risk scoring, and location-based tracking, you can detect and mitigate risks instantly.

## ✨ Features

- **🧠 ML-Powered Detection:** Analyzes 50+ fraud signals in real-time, including geo-mismatch, device fingerprinting, and velocity checks.
- **⚡ Real-Time Monitoring:** Built with Socket.io for instant transaction updates and alerts.
- **📊 Additive Risk Scoring:** Dynamic 0-100 risk score system. High-risk transactions (>75) are automatically blocked.
- **🗺️ Geo-Tracking:** Interactive mapping with Leaflet to visualize and trace transaction origins and detect geo-mismatches.
- **👀 Manual Review Queue:** Medium-risk transactions (40-74) are queued for manual review.
- **🖼️ AI Image Analysis:** Upload images or documents for AI-powered fraud detection.
- **🎨 Modern UI:** Sleek, responsive, and glassmorphic interface built with React, Tailwind CSS, and shadcn/ui, animated with Framer Motion.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/) with [Vite](https://vitejs.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Data Visualization:** [Recharts](https://recharts.org/)
- **Mapping:** [React Leaflet](https://react-leaflet.js.org/)
- **Real-Time Data:** [Socket.io](https://socket.io/)
- **Forms & Validation:** [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Divyansh-31/FraudX-2.git
   cd FraudX-2
   ```

2. **Install dependencies:**
   Using npm:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open the app:**
   Open `http://localhost:5173` in your browser to see the dashboard.
